# Phoebe Towe: Portfolio

Personal portfolio site for a Finance major (Philosophy & Law minor) at Miami University preparing for a career in corporate law.

Plain HTML, CSS, and a little JavaScript. No build step.

## Structure

```
index.html      All page content (edit text here)
css/main.css    Colors, fonts, layout (light + dark themes)
css/print.css   Clean print / "Save as PDF" layout for the resume
js/main.js      Mobile menu, theme toggle, print button, scroll reveal
assets/         Favicon (add a headshot or resume PDF here)
```

## Publish with GitHub Pages

1. Push to `main`.
2. In the repo, open **Settings → Pages**.
3. Under **Source**, choose **Deploy from a branch**, then `main` and `/ (root)`.
4. After about a minute the site is live at `https://phoebetowe.github.io/Portfolio/`.

## Updating

- **Resume:** edit the Education, Experience, and Resume sections in `index.html`.
- **Selected Work:** when a writing sample is finished, add the PDF to `assets/` and link it from its card.
- **Preview locally:** open `index.html` in a browser.
